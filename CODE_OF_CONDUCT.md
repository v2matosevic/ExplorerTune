# Code of conduct

## The short version

Be decent. Argue about the code, not the person.

## What is expected

- Assume the other person knows something you do not.
- Criticise the work, not its author.
- Take "no" without a fight, and give reasons with yours.
- Remember that most people here are doing this in their spare time.

## What is not

Harassment, personal abuse, discriminatory language, deliberate derailing, or
publishing anyone's private information.

Also, specific to this project: **do not use an issue to attack a software
vendor.** Catalog entries describe what a shell extension costs and what breaks
if you block it. That is technical fact and it is welcome. "Vendor X is
malware" is not, and it makes the catalog less useful to the next reader.

## Enforcement

Report a problem through GitHub's private reporting on this repository.
Maintainers will edit, lock, or delete content and may block accounts. Being
right about the technical point does not exempt anyone from this.
